# UDC SMS Assistant - Android OTP Forwarder
========================================================================
সহজে APK তৈরি করার বাংলা নির্দেশিকা (GitHub Actions ও Android Studio)
========================================================================

উপায় ১: GitHub Actions দিয়ে ফ্রিতে ২ মিনিটে APK বিল্ড (সবচেয়ে সহজ ও ১০০% নিশ্চিত)
------------------------------------------------------------------------
১. GitHub.com-এ গিয়ে একটি নতুন রিপোজিটরি (New Repository) তৈরি করুন।
২. ডাউনলোড করা এই জিপের ভেতরের সমস্ত ফাইল ও ফোল্ডার (.github, app, build.gradle ইত্যাদি) রিপোজিটরিতে আপলোড করুন বা পুশ করুন।
৩. GitHub রিপোজিটরি পেজের উপরে থাকা "Actions" ট্যাবে যান।
৪. বামপাশে "Build Android APK" সিলেক্ট করে ডানপাশে "Run workflow" বাটনে ক্লিক করুন।
৫. ২ মিনিটের মধ্যে বিল্ড সম্পন্ন হবে (সবুজ টিক চিহ্ন আসবে)।
৬. সেই রানের ভেতরে ঢুকলে নিচে Artifacts সেকশনে "udc-sms-assistant-debug-apk" ডাউনলোড লিংক পাবেন।
৭. ডাউনলোড করা ফাইলটি আনজিপ করলেই আপনার ফোনে সরাসরি ইনস্টল করার "app-debug.apk" ফাইল পেয়ে যাবেন!

------------------------------------------------------------------------
উপায় ২: Android Studio দিয়ে সরাসরি আপনার পিসি থেকে APK বিল্ড
------------------------------------------------------------------------
১. এই জিপ ফাইলটি আপনার পিসিতে কোনো একটি ফোল্ডারে আনজিপ (Extract) করুন।
২. Android Studio সফটওয়্যারটি ওপেন করুন।
৩. "File" ➔ "Open" দিয়ে আনজিপ করা ফোল্ডারটি সিলেক্ট করুন।
৪. Android Studio নিচে Gradle Sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন (১-২ মিনিট)।
৫. উপরে মেনু বার থেকে ক্লিক করুন:
   Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)
৬. বিল্ড শেষ হলে নিচে ডানপাশে "locate" নোটিফিকেশন আসবে, ক্লিক করলেই আপনার "app-debug.apk" ফাইলটি পেয়ে যাবেন।
